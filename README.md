# Меню на тыдзень

Статычны сайт на беларускай мове: сняданкі і вячэры на сем дзён ад сёння,
па 8 хатніх страў, рэстарацыя і дастаўка. Порцыі разлічаны на двух чалавек.
Стравы можна гартаць свайпам улева/ўправа, кнопкамі-стрэлкамі або клавішамі ←/→ на картцы.
Выбар па датах і адзнакі пакупак захоўваюцца ў `localStorage` гэтага браўзера.

Запуск: `python3 -m http.server 8765`, затым http://localhost:8765.
Для публікацыі дастаткова `index.html` і каталога `assets/`; сервер прыкладання не патрэбны.

Праверкі: `npm ci`, затым `npm test`. Патрэбныя Python 3 і ўсталяваны Google Chrome.
Тэсты правяраюць выбар і захаванне меню, пакупкі, змену дат, ілюстрацыі і мабільную кампаноўку.

Акварэльныя выявы створаны ўбудаваным ImageGen і аптымізаваны ў WebP 640 × 640.
Промпты захоўваюцца ў `assets/meals/prompts.json`.
